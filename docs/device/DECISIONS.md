# Device and circuit layer v0: decisions

Written 31 Oct 2026 (IST). Decisions 1-4 were made before this work and are not reopened here.
Decisions 5 onward were made while building v0; each says why.

## Fixed before the work started

1. **Model = the recipe of `docs/lit/device_models.md` §1.** An N-domain kinetic Preisach ferroelectric
   with each domain state on its own internal node (N = 16 by default, a parameter), the NLS
   (Alessandri) switching rate, the ferroelectric between the gate g and an internal node m (MFMIS
   lumping), polarization charge plus a linear dielectric charge. No hidden variables, no `@(cross)`,
   smooth functions, capped exponents.
2. **Two implementations of the same equations.** (a) `device/veriloga/fefet_preisach.va`, the
   canonical source, written for OpenVAF/OSDI (not compiled: OpenVAF is not installed); (b)
   `device/ngspice/fefet_preisach.lib`, an ngspice-native subcircuit of B-sources and 1 F state
   capacitors, generated by `scripts/gen_fefet_lib.py`. The equation-by-equation note is
   `docs/device/MODEL_EQUIVALENCE.md`.
3. **MOSFETs: our own stand-in BSIM4 cards** (`models/mosfet/standin45_bsim4.lib`, nmos45/pmos45),
   labelled "uncalibrated stand-in, not a PDK". Every deck includes them through one `.include` line,
   so a real card can be swapped in by changing that line.
4. **Calibration order:** parameter set B (Ni 2018 film) first, then set C (TCAM-class device) for the
   TCAM circuits.

## Made during v0

5. **ngspice is always run with `-n`.** A user's `~/.spiceinit` sets HSPICE compatibility mode
   (`ngbehavior=hsa`, probably for SKY130). `-n` keeps our decks independent of it.
6. **Set B uses β = 1.64 (fitted), not β = 1.** With β = 1 the fit to the pulse table T3 left 8 of
   60 points outside ±3 µC/cm² (RMS 2.0); the data rise more steeply in log(t) than one exponential.
   The recipe's β ≠ 1 form (R3b) is used. Sets B and C keep their own kinetics (risk R4).
7. **Neutral start.** Every FeFET simulation starts with all node voltages at 0 V and all domain
   states at x = 0. This fixes the charge trapped on the floating node m (P = 0 is neutral at
   V_G = 0). The absolute V_th then depends on this choice and on vth0; vth0 is fitted, so the
   choice is absorbed.
8. **Saved states ("snapshots").** A device state (16 domain states plus V_m) can be saved from one
   run and used to start another (`x0_i` parameters plus `.ic` on node m). Long holds, reads after
   holds, and all TCAM searches start from saved states, so no deck has to cover both
   nanoseconds and years. The restart reproduces the original read within a few mV (test 1e).
9. **V_th variation is applied as a gate-referred shift `dvg`** (a voltage source in series with the
   FeFET gate), so V_th moves by exactly dvg in both states. BSIM4 `delvto` on the channel is still
   available (`dvt`), but its effect on the FeFET V_th depends on the state (roughly ×1-2 here,
   because the trapped charge on node m stays fixed), which would make σ(V_th) state-dependent in
   an uncontrolled way.
10. **Write scheme: two phases with V_W/2 inhibit through the row well.** Phase 1: every gate line at
    −4 V (selected row to high V_th); phase 2: the gate lines of FeFETs that must be low V_th at
    +4 V, the rest at 0 V. The selected row's ML, ScL and well stay at 0 V (as Ni 2019 describes);
    unselected rows put −2 V (phase 1) or +2 V (phase 2) on their ML, ScL and well, so no
    unselected FeFET sees more than |2 V|. A negative gate cannot be inhibited through source and
    drain alone (the channel is in accumulation), so this needs a separate (triple) well per row.
11. **Search levels: VDD = 1.0 V (precharge, sense amplifier), V_S = 1.1 V on search lines.** V_S
    sits between the two thresholds (0.65 / 1.68 V); 1.1 V gives about 4.5 σ to the low-V_th tail
    and 3.9 σ to the high-V_th tail with Ni 2019's σ values.
12. **Read wait 2 s for both sets.** P1 states 2 s; Ni 2019 states none. V_th criterion: 1e-7 A per µm
    of width (set B, as P1) and 1e-7 A × W/L (set C), both at V_DS = 50 mV, read with a 26 µs gate ramp.
13. **Set C's P_S is fitted.** The document gives no value (22.9 µC/cm² was only a start). The fit
    prefers a small effective switchable polarization (about 3 µC/cm²): the window then saturates
    because the switchable charge runs out, which is what the Ni 2019 iso-MW data show between 3.66
    and 4 V. Read this as "effective switchable polarization of the MFIS stack", not as the film's P_r.
14. **Target C6 was added to the set-C fit** (no switching at the search level, +1.1 V for 1e5 s),
    after the first fit gave strong read disturb. Without it the fitted field exponent was low
    (α ≈ 1.6), and searches at 1.1 V would slowly reprogram high-V_th cells.
16. **Nanosecond searches use frozen-domain FeFETs** (`fefet_c16_frozen`: the linear FE capacitor plus
    the MOSFET, started from a saved state). During a 1 ns search at ≤ 1.1 V no domain can move, so
    this is the same circuit; on the 14 cases of test 3b it matches the full model to 0.000 % in time
    and energy, at about 1/30 of the run time. Writes, holds and disturb tests use the full model.
17. **Monte Carlo decks write measurements, not waveforms.** ngspice `meas` gives each word's
    discharge time and SA state; supply charges come from a trapezoid `integ()` vector read at the
    cycle edges (ngspice's `meas ... integ` was 2-5 % off). Checked against the waveform path: equal to
    4e-6 on a full deck.
18. **The count is read in the time domain** (time for the sense-amplifier output to switch after the
    search lines rise). A time-to-digital converter is not built in v0; the testbench measures the time.
