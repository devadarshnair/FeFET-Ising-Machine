# P4.03 — B3 Fujitsu DA: golden config + digital cost mapping (16 Nov 2026 IST)

Code: `scripts/baselines/fujitsu_da.py` (sheet docs/hw/lit/aramon2019_da.md; label "literature-parameterised").
Tests: `tests/hw/test_b3.py` 10/10 (offset +rate per no-accept step and reset on accept, rate 0 holds E_off = 0,
lin-beta schedule, SK QUBO = Ising, digital cost with no ADC/array). tests/hw 115/115. RTL `b3_maxcut16` (digital field,
da_offset rate 1, uniform select, geometric schedule) bit-exact vs golden; cfg in `rtl/cfg/b3_da.cfg`.

Config: parallel trial over all lanes, one accepted lane chosen uniformly (select_tree), dynamic offset per Alg. 2
(default rate 0 = paper's final setting; positive rate = ablation; rate unpublished), start x = 0, no restarts.
Deviations (stated): RTL temp_sched is geometric, so Aramon's linear-in-1/T schedule (`schedule="lin_beta"`) is a
golden-only override used for P4.04; the shared datapath computes with 10 b couplers / 12 b biases while costing is at
the DA's 16 b / 26 b; RNG = golden xoshiro lanes (paper: TGFSR).

P4.08: this table (+ b3_extra) is now the single canonical table for ours, B1, B2 and B3 (`cost_model.canonical_table`, hash-tested).
Cost (digital, not FeFET CiM): golden op counters x the P3.11-corrected table `docs/hw/energy_table_v1_p309.csv`
(copied from hw/p3-rtl @ 573cbb7 with `docs/hw/results/p309_gate_counts.csv`) + SRAM rows in
`docs/hw/energy_table_b3_extra.csv` (LITERATURE, not characterised: Horowitz ISSCC 2014 45 nm 8 KB read 156 fJ/bit,
band 0.25-4x; 45 nm 6T cell 0.346 um2 x 1.5 = 0.52 um2/bit). Per accepted flip one coupler row (n x 16 b) is read.
Area = (n^2 x 16 + n x 26) SRAM bits + n x (g_digital_per_lane + g_rng_per_lane) + select_tree + offset adder.
Width caveat: Yosys lane counts are at 10/12 b (lower bound for 16/26 b field part); the M3 architecture caveat
of g_digital_per_lane applies equally to B3.

Example (n = 256, SK-bimodal, lin-beta 42 -> 2, 5000 iterations): energy per iteration ~775 pJ, of which SRAM
reads 631 pJ (flip almost every iteration), digital 50 pJ, RNG 94 pJ. Cell area n = 64: 1.06 mm2; n = 256: 4.66 mm2
(digital lanes 68 %, SRAM 12 %; select_tree N = 256 = P3.11 scaled estimate 5169 NAND2-eq).
