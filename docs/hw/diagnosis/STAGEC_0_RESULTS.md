# Stage C.0 result: go / no-go gate on the Stage 3.2 records re-priced under measured_v4 (exploratory screen, zero new simulation)

Gate as declared in `STAGEC_PLAN.md` section 2 (internal review s20 fix 5): **go requires a WIN (not "no loss") against B3_sel at p4n480 or p3n480 on the Stage 3.2 records re-priced under measured_v4, both at nominal pricing AND at analog hardware estimates x2**, plus an ideal-restoring correction-table size at the five bracket points.
Method: `scripts/testing/s3_reprice_v4.py` (7c15683) re-run on the unpacked Stage 3.2 records (64 x 3 colouring cells), registered rule (dual-B3, margin -0.10, EVAL-1, Holm m = 8), B = 2000; my re-run **reproduces the rows exactly** (`sc_c0_evidence/`). Candidate primary: `all,b3b,t1f,m3,m4,t6s`, SRAM table k = 64, lstp cells, no T-5 (OpenRAM read + CACTI lstp leakage: the B3-favourable hybrid). the engineering notes s16 (wide-word / array-only B3 SRAM bound) had not landed; it only affects the robust tier, not this gate.

**Literal reading of the gate: NOT MET.** At nominal the p4n480 contrast is a win; at analog x2 it is "inconclusive" (ratio 0.71 <= 0.95 but the 97.5 % upper bound 0.96 sits just above the win threshold and, with Holm m = 8, the adjusted p is above 0.05); p3n480 is inconclusive at both. Under the gate as written Stage C is a no-go.
**Why it is a near miss, not a clear failure (for the authors' decision, not an override):** the Stage 3.2 records have 64 instances per cell; the relative half-width of the ETS interval at 64 instances is about 0.35 and falls to about 0.20 at the proposed 192 instances (STAGEC_PLAN s3). At a true ratio of 0.71 the probability of a win at 192 instances is about 0.65-0.70 (power table: 0.93 at 0.65, 0.48 at 0.75); at p3n480 (true 0.75-0.82) it is 0.3-0.5 and at 0.82 below 0.2. So Stage C would more likely than not confirm "supported" at p4n480 at nominal, but it would not reliably confirm the analog-x2 condition; the robust tier (B3 SRAM / RNG x0.5: 0.70-0.76 at p4) is not resolvable, as pre-declared.
**What the screen also shows (exploratory):** the v4 candidate is the B3-favourable corner (lstp cells for both machines, OpenRAM 49.5 fJ/bit read): with hp or OpenRAM leakage both machines' SRAM leaks more and the p4n480 / p3n480 ratios fall to 0.48 / 0.56 (hp) or 0.38 / 0.45 (OpenRAM cells); B3 un-gated 0.58 / 0.68; full gating on both 0.73 / 0.85; B3 SRAM read x0.5 0.70 / 0.81; B3 RNG x0.5 0.71 / 0.82; both x0.5 without B3 leakage 0.76 / 0.89.
**Not run (cost-benefit):** the table-size check at p3n240 and the esc off / esc A check (about 1.5 h local) were not run because the gate result decides first whether Stage C proceeds; they are cheap to run if the authors choose go. **Decision needed:** no-go (stop; the positives stand as reported in Stage 3.2 with the v4 and T-5 errata) or go with the stated power (about 0.7 for the p4n480 supported tier, p3n480 unlikely to resolve).
