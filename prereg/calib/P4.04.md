# P4.04 prereg: B3 (Fujitsu DA, Aramon 2019) calibration — TOLERANCE FILE

Frozen before any scored run (IMPL_PLAN "Rule for every calibration task"). Committed alone; the runner
`scripts/baselines/calib_b3.py` holds the numbers below as constants and refuses to run unless this file is committed
unchanged (sha256 printed in every RESULT line). Calibration is against Aramon's own paper only, never our design.

## Paper numbers (Aramon et al., arXiv 1806.08815v3 / Front. Phys. 2019; sheet docs/hw/lit/aramon2019_da.md)
- C2: TTS80 scaling exponent beta in log10 TTS = alpha + beta N, fully connected SK, DA: 0.0021(7) bimodal,
  0.0019(3) Gaussian (Sec. VI.B). DA time per iteration is independent of N (Sec. II.B), so the exponent in
  iterations equals the exponent in time.
- C4: parallel-trial acceptance boost at low T, factor ~N (Sec. III, Fig. 2; all classes except 2D-bimodal).
- Offset: the DA performed best with the dynamic offset OFF on the spin-glass benchmark ("indifferent", App. A).
- Not calibrated (stated): C1 (>= 100x over CPU SA/PT: absolute seconds only in log-plots, a CPU-time comparison our
  model cannot make), C3 (2D-bimodal N = 1024, 52/100: N = 1024 x 1e7 iterations is out of the time box), 3D and
  Max-Cut (none in the paper).

## Instances, machine, schedule, seeds
- SK-bimodal (J = +-1) and SK-Gaussian (J = round(10 N(0,1)), integer-scaled as Aramon scale by 1e5), sizes n = 64, 128,
  256, 20 instances per (class, n) (`fujitsu_da.sk_qubo(n, i, kind)`, i = 0..19). QUBO P = 4J, d = -2 sum_j J
  (fits the shared 10 b / 12 b datapath; asserted). Aramon use 9 sizes 64-1024 and 100 instances (deviation: budget).
- Machine: shared golden machine, B3 config of P4.03 (`fujitsu_da.B3Machine`): parallel trial, uniform select of one
  accepted lane, dynamic offset arm da_offset, start x = 0 for every run, digital exact field, no restarts.
- Schedule: linear in 1/T over the run, T updated every iteration (App. A); Th = 82.5th, Tl = 7.5th percentile of
  nonzero |dE| of single-flip proposals over 200 uniform random states of the instance (App. A rule: 80-85th /
  5-10th; midpoints registered). Per instance, shared by both arms.
- Budget: L(n) = 400 n iterations per run (64: 25600, 128: 51200, 256: 102400); 50 runs per (instance, arm),
  run r seed = mix_seed(20261116, class, n, i, r), common to both arms.
- Arms: OFF = offset rate 0 (paper's final setting); ON = offset rate max(1, round(Tl / 4)) energy LSB per no-accept
  step (rate unpublished; registered ablation value).

## Success, TTS, targets and tolerance (PLAN: TTS within x2, direction of offset effect identical)
- Reference E*(instance) = best objective found by any run of either arm of attempt 1 (no PT ground state is
  available; self-referenced, labelled). A run succeeds iff its best-so-far reaches E* within L(n).
- TTS99 = min over t of t x R99(p(t)), R99 = ln(0.01) / ln(1 - p) (1 if p = 1), p(t) = fraction of the runs whose
  best-so-far reached E* by iteration t (best_step); inf if no run reached E* (Sec. IV definition with the anneal
  length chosen optimally, as Aramon tune it, so that a fully successful budget does not fix TTS = L(n)).
  TTS80(class, n, arm) = 80th percentile of TTS99 over the 20 instances (inf counts as +inf); sigma by bootstrap over
  instances (B = 2000).
- T1 (bimodal) and T2 (Gaussian): beta = least-squares slope of log10 TTS80(OFF) vs n over n = 64, 128, 256.
  PASS iff beta_paper / 2 <= beta <= 2 beta_paper (0.00105-0.0042 bimodal; 0.00095-0.0038 Gaussian). Any infinite
  TTS80 -> FAIL ("target not reached in budget").
- T3 (offset direction): q = geometric mean over the 6 (class, n) cells of TTS80(ON) / TTS80(OFF). Paper direction
  "offset does not help" -> PASS iff q >= 0.5 (ON is not more than 2x better). Infinite cells excluded; all excluded -> FAIL.
- T4 (C4 boost): in the last 10 % of iterations of every OFF run at n = 256, boost = n P(c > 0) / E[c]
  (`fujitsu_da.acceptance_boost`); median over runs and instances, per class. PASS iff median >= n / 2 for both classes
  (runs with no acceptance in the window are excluded and counted).
- Output: `RESULT P4.04 T<k> PASS|FAIL value=... sigma=... attempt=... prereg_sha256=...`.

## Single repair attempt (attempt 2, only for a FAIL in T1/T2)
L(n) = 1000 n, 25 runs per instance, OFF arm only, same instances, schedule and reference rule (E* re-taken as the best
over attempt 1 and attempt 2 runs). T3/T4 are not repaired. After attempt 2 a still-failing target is labelled:
B3 = "literature-parameterised DA-style digital annealer, Aramon TTS scaling not reproduced" (IMPL_PLAN default
label "not reproduced"); P5/P6 go on.

No other knob (sizes, instance count, budget, T rule, offset rate, reference rule, tolerances) may change after this
file is committed.
