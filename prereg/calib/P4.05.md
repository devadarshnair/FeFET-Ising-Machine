100 initial states x 100 runs per (instance, arm, config). Every config reports per-run and per-init rates
(per-init = best of the init's 100 runs >= 0.95 opt) under three scorers (H3): best-seen feasible, final-state

- C1 (H1): L = 1000 proposals; H1 reading = per-init, both arms.
- C2 (H2): L = 1000 sweeps = 1000 x (n + C) proposals for D-QUBO, 1000 x n for the filter; per-run reading.
  H1+H2 jointly = C2 under the per-init reading (same runs).
- C3 (H4): best of {C1-per-init, C2-per-run, C2-per-init} by |D-QUBO rate - 10.75| (best-seen scorer) = the "winning
  reading" W; C3 = W with D-QUBO init = consistent (feasible_random x, y = e_{w.x} if 1 <= w.x <= C else y = 0).
- C4, C5 (H5): W with the D-QUBO T0 multiplier 1e-3 and 1e-5 (instead of 1e-4).
A config's D-QUBO rate is "in band" iff in [5.75, 15.75] and its filter rate (same reading, same scorer) in [93.54, 100].

## Full stage (40 instances) and pass rule
Best registered interpretation B = among the (config, reading, scorer) cells of the diagnosis that are in band, the
one with the smallest |D-QUBO - 10.75|; if none is in band, the cell with the smallest |D-QUBO - 10.75| regardless.
B is selected by the script from the diagnosis file only (no manual choice), then run on all 40 instances with
100 initial states x 100 runs. `RESULT P4.05 PASS` iff the 40-instance D-QUBO rate is in [5.75, 15.75] and the filter
rate under the same reading in [93.54, 100]; else `RESULT P4.05 FAIL`.
FAIL is an acceptable outcome: docs/hw/results/P4.05.md "D-QUBO not reproduced under k registered interpretations",
status DONE-NEG. A PASS reached only via a per-init reading is labelled "reproduced only under the best-of-100
reading" (REPRO_DESIGN §3 ii). No other knob may change after this file is committed.
