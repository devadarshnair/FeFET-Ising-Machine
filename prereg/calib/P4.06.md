## Filter hardware (interpretation, recorded)
- Weight array 16 rows x 100 columns of 1FeFET1R cells, 5 levels per cell = cim_cell_v1 levels 0-4 (unit current
  I_u = I_1, ~14.16 nA). Item weight w_i (1..50 on Billionnet-Soutif) = sum of its column's digits: floor(w_i/4) cells
  at level 4 plus one cell at w_i mod 4, rest level 0 (16 x 4 = 64 >= 50). Column i is enabled iff x_i = 1.
- Replica array (same geometry) holds C units the same way plus one half-unit reference (I_u/2), so the comparator
  accepts iff I_ML < I_rep, i.e. w.x <= C exactly at sigma = 0 (no ties).
- Multi-level handling (P1.10 t4e: open-loop levels 1-6 not reliable): **per-cell write-verify**, because the plan
  fixes 5-level cells for B2 (PLAN B2 row, IMPL_PLAN P4.06); bit-slicing would change the published architecture.
  Programming is cell-by-cell (P1.07 fallback). Write-verify residual model: each verified cell's current uniform in
  target +-5 % (the t4a acceptance band). Expected attempts per level k = 1 / P(|N(0, sigma/mu_k)| < 0.05)
  (retry-until-pass estimate from the t4e sigma/mu); each attempt = e_write_fJ + one verify read (e_read_fJ), time
  t_write_us + 20 ns. Level 0 is not verified (open-loop, current max(0, N(mu_0, sigma_0))).
- Open-loop variant (info, the "char sigma" case): every level max(0, N(mu_k, sigma_k)) from cim_cell_v1.
- Comparator: ideal decision; energy per decision = e_cmp_fJ(bits=3)/3 from adc_energy.csv; offset (7.4 mV, P1.11)
  not mapped to current (no transimpedance model) -> recorded caveat. Write-disturb (P1.07 term) is reported as a
  stress-time ratio only; no I(Vth) map exists to apply it.
