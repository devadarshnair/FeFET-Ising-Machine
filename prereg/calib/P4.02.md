# P4.02 prereg: B1 (Yin 2024 MESA) calibration, R1 algorithm level — TOLERANCE FILE

Frozen before any scored run (IMPL_PLAN "Rule for every calibration task"). Committed alone; the runner
`scripts/baselines/calib_b1.py` reads the numbers below from its own constants and asserts this file is committed
unchanged (sha256 recorded in each output row). Calibration is against Yin's own paper only, never our design.

## Paper numbers (Yin et al., Nat. Commun. 15:2419, 2024; parameter sheet docs/hw/lit/yin2024_supp.md)
- T1 "+27 %": "up to 27 % improvement in cut value for 3000-node problems" (Main, Results, Fig. 4b text; abstract
  "up to 27 % better solution"). Baseline = conventional SA (inferred from Fig. 4b context; sheet row 27).
- T2 "~2x": "about 2x speed-up" (abstract), from SI Fig. S7a,b p. 11 (MESA vs conventional SA on "Gset1", 800-node
  Max-Cut; MESA reaches 100 % solved, SA 90 %; no numeric time; sheet rows 26, 28).
- Instances: 30 problems, 800-3000 nodes, Stanford G-set, IDs not published (sheet row 25).

## Our instances, machine, seeds
- G-set equivalents (inferred, IDs not published): 30 graphs, 800-3000 nodes:
  G1-G5 (800, random unit), G6-G10 (800, random +-1), G11-G13 (800, toroidal +-1), G14-G17 (800, planar unit),
  G22-G26 (2000, random unit), G43-G47 (1000, random unit), G48-G50 (3000, toroidal unit). Loader: scripts/problems/
  maxcut.py (read-only copy of hw/p5-map @ 0350dd3). Best-known cuts from the G-set BKS csv (reference only).
- Machine: the shared golden machine (scripts/golden/tim_golden.py), B1 config of P4.01 (scripts/baselines/
  yin_mesa.py): MESA restart arm, Count_max = 2n, deoff = 0, I7/I10 off, start state x = 0, padded to the next power
  of two with lane_en. Algorithm level (R1): the field is the exact integer field; the tiled CiM field equals it at
  sigma = 0 (tests/hw/test_b1.py::test_tiled_field_exact_at_sigma0), so it is not simulated here (cost only).
- SA baseline: the SAME machine and schedule with restart arm "none" (no escape). Only the restart differs.
- Move set deviation (stated): Yin's MESA perturbation "flipping a few bits" (sheet row 21) is NOT used. The shared
  machine proposes one single-flip per step for every architecture; MESA differs only by its stall restart.
- Schedule: geometric over the whole run (golden geom). T_start = 85th percentile, T_end = 5th percentile of the
  nonzero |dE| of single flips over 32 uniform random states (Aramon 2019 App. A rule, sheet row 20). Same T for
  both arms on an instance.
- Budget: 300 sweeps = 300 n single-flip steps per run (n = graph nodes); best-so-far cut recorded every sweep.
- Seeds: 20 per (instance, arm), s = 0..19; machine seed = mix_seed(20261115, instance index, s), shared by both arms
  (common random numbers).

## Targets, success definitions, tolerance (PLAN 2.3 R1: +-10 pp or +-1 sigma over >= 20 seeds, looser wins)
- T1: imp_g = (mean_s cut_MESA - mean_s cut_SA) / mean_s cut_SA x 100 at the end of the budget, for g in G48-G50;
  T1 = max_g imp_g ("up to", 3000-node). sigma = bootstrap SD of T1 over seeds (B = 2000, resample seeds per arm).
  PASS iff |T1 - 27| <= max(10, sigma).
- T2: target cut = 0.99 x best-known. For each of G1-G5 and arm: p(t) = fraction of the 20 seeds whose best cut
  >= target by sweep t; TTS = min_t t x R99(p(t)), R99 = ln(0.01)/ln(1-p) (1 if p = 1; undefined if p = 0)
  (Aramon 2019 Sec. IV definition). speed-up_g = TTS_SA / TTS_MESA; T2 = geometric mean over the instances where
  both are defined (if MESA defined and SA not on every instance: T2 = "> budget", FAIL; if none defined: FAIL,
  label "target never reached"). sigma = bootstrap SD of T2 (B = 2000). PASS iff |T2 - 2| <= max(0.5, sigma)
  ("about 2x" read as 1.5-2.5; a ratio has no pp scale, so +-25 % is the registered analogue).
- Output: one line per target `RESULT P4.02 T<k> PASS|FAIL value=... sigma=... attempt=...`.

## Registered interpretation choices (<= 3; P0.07 R1 choices) and the single repair attempt
1. Count_max = 2n stagnant steps (attempt 1).
2. Stall = no strict improvement of best-so-far; on stall reload best, T := T0 (golden mesa arm).
3. RNG = off-array digital generator (golden xoshiro lanes).
Repair attempt 2 (run only for a target that FAILs in attempt 1; PLAN 2.3 "one documented repair attempt"):
Count_max in {n, 4n} (the P0.07 sensitivity values), MESA arm only, SA runs of attempt 1 reused. A target passes in
attempt 2 if either value passes; the value is named. After attempt 2 a still-failing target is labelled:
B1 = "literature-parameterised generic FeFET CiM annealer, R1 not reproduced" (IMPL_PLAN P4.02 fail rule); P5/P6 go on.
R2 is waived: Yin publish no energy/time figures (sheet row 32); label "literature-parameterised".
